## Arquivos presentes

Esta pasta reúne materiais utilizados para estudar o método da janela, incluindo:

- implementações em Python para projeto de filtros FIR;
- geração das principais funções janela;
- cálculo da resposta ao impulso ideal;
- gráficos da resposta em frequência;
- exemplos utilizados durante as aulas;
- anotações sobre os conceitos teóricos.
